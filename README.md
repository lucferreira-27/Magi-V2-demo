# MangaAnalyzer Docker

This project provides a Docker container for the MangaAnalyzer tool, which analyzes manga pages and recognizes characters.

## Requirements

- Docker
- Docker Compose
- NVIDIA GPU with CUDA support
- NVIDIA Container Toolkit (for GPU support)

## Setup

1. Place your manga pages in the `test_assets/pages` directory
2. Place your character reference images in the `test_assets/characters` directory
